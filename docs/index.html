Ipynb PDF Converter

Jupyter 노트북(.ipynb)과 마크다운(.md)을
우클릭 한 번으로 종이 규격 PDF로.

VS Code Marketplace에서 설치 GitHub

하는 일

  • 📋
    텍스트 복사 · 검색

    PDF의 글자를 드래그해서 복사하고 검색할 수 있습니다.

  • ✂️
    자르지 않는 페이지 나누기

    글줄 · 표 행 · 그림 중간에서 페이지가 끊기지 않습니다.

  • 📐
    종이 · 태블릿 규격

    A4 · B5 · Letter 같은 용지와 iPad · Galaxy Tab 화면 크기.

  • 🎨
    테마

    페이지 테마 3종과 코드 하이라이트 11종.

  • 🔒
    비밀번호

    AES-256 암호화와 인쇄 · 복사 권한 설정.

  • 📦
    설치할 것 없음

    Python · nbconvert · Chromium 없이 VS Code만으로.

시작하기

ext install leekh.ipynb-pdf-converter
  1. .ipynb 또는 .md 파일을 우클릭
  2. PDF로 변환 → 노트북/마크다운을 PDF로 변환 선택
  3. 같은 폴더에 PDF가 생깁니다
